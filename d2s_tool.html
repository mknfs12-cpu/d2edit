D2 Survivors 세이브 도구

세이브 코드를 붙여넣고 버튼을 누르세요. 전부 기기 안에서 처리됩니다.

1. 세이브 불러오기

또는 아래에 세이브 코드를 직접 붙여넣으세요.

2. 현재 상태

골드-
모드-
빌드-
봉인-

3. 골드

상한 10,000,000,000. 넘으면 게임 검증에 걸려 edited 표시가 붙습니다.

4. 업그레이드 항목별 수치

기본 랭크와 추가 수치를 구분해 표시합니다. 아래 입력란은 추가 수치(extraRanks)만 변경합니다. 변경하지 않은 항목과 나머지 세이브 데이터는 유지됩니다.
항목
기본
추가 수치
각 항목은 0 이상의 정수로 입력하세요. 입력한 값은 추가 수치로 저장됩니다.

5. 정수(에센스)

Burning Essence of Terror 스택
Larzuk's Essence 스택
스택 하나 = 99개 고정입니다. 원하는 스택 개수를 입력하세요.
입력한 개수만큼 인벤토리/보관함에 스택을 만들고, 각 스택을 99개로 채웁니다.
스택은 1칸(1x1)을 차지하며, 기존 스택 위치와 겹치지 않게 배치됩니다.

6. 지옥불(대장간) 막힌 아이템

강화 유지 초기화는 작동하지 않습니다. 서버가 서명(h)으로 검증하는데 그 키가 클라이언트에 없어 위조할 수 없습니다. 시도하면 서버가 강화를 되돌립니다.
0강으로 초기화하면 서버가 모르는 아이템이 되어, 10강부터 다시 쌓으면 지옥불이 정상 작동합니다.

7. 내보내기

게임의 Save Transfer 창에 붙여넣으면 적용됩니다.
